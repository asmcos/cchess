# 棋谱页 · 中国象棋棋谱浏览器

xqbook 是代码开源、使用免费的背谱打谱软件，同时也是一个学棋社区。本页是它的棋谱页：在线阅读、打谱、背谱。库里收藏了 **三十万余局**棋谱（XQF），比赛对局、布局、中局、残局、排局和名局都有，足够大家学习。支持**开局分类检索**、**残局排局复盘**、**背谱记忆**、**分叉变着浏览**。目录和分类都按页加载。

站点首页见 [README.md](README.md)。本页只说明棋谱。

> 项目首期棋谱来自： https://github.com/zhengguozi/chess_book/
后来有增加了30万棋谱。

> 项目主页：https://xqbook.cn

## 入口

线上棋谱页是 [https://xqbook.cn/qipu](https://xqbook.cn/qipu)，首页是 [https://xqbook.cn/](https://xqbook.cn/)。

自己部署时在本机打开：

```bash

```

## 核心功能

### 海量棋谱 · 开局分类检索

全库 **三十万余局**中国象棋棋谱，可按**一级/二级开局**过滤。点开一类先看到大纲，再一页一页取棋谱：

- **开局定式**：中炮局、飞相局、仙人指路、起马局、过宫炮局、仕角炮局、上士局、其它炮局
- **二级体系**：中炮对屏风马、中炮对顺炮、中炮对反宫马、仙人指路对卒底炮、中炮进三兵对屏风马
- **经典古籍**：全局（橘中秘、事林广记）、残局（适情雅趣）、排局（江湖八大排局：七星聚会、炮炸两狼关、三军保驾）
- **实战对局**：比赛对局、象甲联赛、大师专集、近代国手名局、让子局、实战中局夺子取胜技巧 150 局

### 背谱模式

- 点「**背**」进入背谱模式，可设置**起点步数**（默认 15 步内随机开始）
- **自己动手走子**：走对了自动继续；走错了即时提示「原谱第 N 步应为 XX」
- 支持**红方视角 / 黑方视角**切换：红视角红人工走、黑自动应；黑视角反之
- 适合背开局定式、背残局杀法、记忆经典对局

### 打谱复盘 · 分叉变着

- SVG 棋盘逐步行棋，支持**前后步 / 首末 / 自动播放 / 键盘方向键**
- **分叉/变着**：多分支着法以绿色标记，点击进入该分支
- 棋盘可**红黑翻转**
- 行棋提示、棋谱注解、棋谱内标题一并展示

### 多端与连续浏览

- 桌面端左右分栏（棋盘 + 着法）；手机端纵向布局
- 地址栏带 `#path=`，分享后直达同一棋谱
- 「**上一谱 / 下一谱**」连续浏览，开局过滤与分类树一起用

## 启动

```bash
# 1. 安装依赖（仅需 cchess）
pip install cchess

# 2. 生成本机数据（catalog.db、pos.db 不在仓库里，必须自己生成）
bash build.sh

# 3. 启动服务（默认端口 8945）
python3 server.py

# 4. 本机打开棋谱页。线上是 https://xqbook.cn/qipu
open http://127.0.0.1:8945/qipu
```

`bash build.sh` 在本机生成 `catalog.db` 和 `pos.db`，这两个文件已写入 `.gitignore`，不会提交。没有 `catalog.db` 时仍可按书浏览。分类和开局过滤要等生成跑完。网页按页读取，不一次下完整库。

## 技术栈

- **后端**：Python 标准库（`http.server`）＋ `cchess` 解析 XQF
- **前端**：原生 JavaScript ＋ SVG，无框架
- **开局识别**：红方第一步 + 前 8 步主变，判定一级/二级开局

## 本页相关文件

```
web/
├── qipu.html            # 棋谱页
├── chess.css            # 棋谱页样式
├── app.js               # 棋盘、目录、分类、背谱、分叉
server.py                # /qipu 指向本页；/api/tree、/api/cat、/api/game
openings.py              # 一级 detect_opening + 二级 detect_opening2
build.sh                # 部署时生成 catalog.db、pos.db 和流行谱分叉
```

架构细节见 `docs/设计文档.md`。

## 棋谱分类

库中棋谱按书籍/主题分册：

1. **比赛对局**（联赛、名手对局、东萍赛事）
2. **布局**（中炮、仙人指路、飞相、起马等开局）
3. **残局**、**排局**、**中局**
4. **名局**、**全局**（橘中秘等经典古谱）、**大师专集**
